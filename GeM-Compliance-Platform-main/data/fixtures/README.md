# Seed Fixtures

These JSON files are synthetic prototype data and mock verification data.
They are intended for deterministic local development and integration testing.

`requirements.json` is the canonical backend seed requirement set.
`TND-*_requirements.json` contains corrected, frozen AI extraction output after
it has been adapted into the canonical requirement contract for the synthetic
single-page tender text fixtures.

They are not live government records or live government API responses.
